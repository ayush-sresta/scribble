# Scribble

A real-time multiplayer drawing and guessing game where players take turns drawing words while others race to guess them.

## Overview

Scribble is a browser-based multiplayer game designed to bring people together through drawing and guessing. Players can create rooms, invite friends, compete for points, and enjoy multiple rounds of gameplay.

## Features

- [ ] Create and join multiplayer rooms
- [ ] Real-time drawing synchronization
- [ ] Interactive drawing canvas
- [ ] Live chat and word guessing
- [ ] Random word selection
- [ ] Turn-based gameplay
- [ ] Real-time scoreboard and scoring system
- [ ] Game rounds and countdown timers
- [ ] Player reconnection handling
- [ ] Game history and player statistics

## Tech Stack

**Frontend**
- Next.js
- TypeScript
- Tailwind CSS
- HTML Canvas API

**Backend**
- Node.js
- Express.js
- Socket.IO
- MongoDB
- Mongoose
